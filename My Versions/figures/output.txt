=== Task 5: Cyclic prefix and multipath ===

  Channel: h = [1, 0, 0.4]  (sheet example, mild)   memory = 2 samples (CP = 16)
    WITHOUT CP : BER = 0.000e+00   EVM = 0.0057
    WITH    CP : BER = 0.000e+00   EVM = 0.0000

  Channel: h = [1,0,0,0,0,0.7]  (stronger, delay 5)   memory = 5 samples (CP = 16)
    WITHOUT CP : BER = 6.594e-03   EVM = 0.1005
    WITH    CP : BER = 0.000e+00   EVM = 0.0000

  Even a mild echo distorts the subcarriers (EVM > 0) without a CP;
  a stronger echo turns that distortion into actual bit errors.
  Adding a cyclic prefix longer than the channel memory turns the
  channel into a clean per-subcarrier multiply -> EVM ~ 0, BER = 0
  after one-tap equalisation.  (All runs here are noise-free, so the
  only impairment is the multipath.)
   [saved] figures/task5_cyclic_prefix.png
